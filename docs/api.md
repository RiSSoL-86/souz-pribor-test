# API

`POST /api/product-cards/` — генерирует карточку и возвращает её в JSON.

## Запрос

```json
{
  "name": "Манометр показывающий DM 02",
  "manufacturer": "Манотомь",
  "specs": {"диапазон измерений": "0–1,6 МПа", "класс точности": "1,5"},
  "description": "Для измерения избыточного давления..."
}
```

Обязательно только `name`. Пустые строки считаются отсутствием данных.

## Ответ

| Поле | Что |
|---|---|
| `seoTitle` | до 70 символов |
| `seoDescription` | 800–1200 символов |
| `specs` | `[{name, value}]`, где нет данных — `"данных нет"` |
| `searchQueries` | 3–5 запросов |
| `commercial` | `audience` — кому подходит, `tasks` — какие задачи решает |
| `missingFields` | каких данных не хватает |
| `needsClarification` | противоречия во входных данных |
| `warnings` | что не прошло автопроверку — вычитать руками |
| `markdown` | вся карточка одним Markdown-документом |

## Ошибки

Формат: `{"detail": [{"msg": "...", "loc": [...]}]}`

| Код | Когда |
|---|---|
| 400 | Битый JSON, нет `name`, неверные типы или длины |
| 422 | Нет ни `specs`, ни `description` |
| 502 | OpenAI отклонил ключ, отказал по региону (нужен `OPENAI_PROXY`) или вернул неразборчивый ответ |
| 503 | Нет ключа, лимит запросов, OpenAI недоступен или не ответил за таймаут |

## Настройки (`src/.env`)

| Переменная | По умолчанию |
|---|---|
| `LLM_PROVIDER` | `open_ai` |
| `OPENAI_API_KEY` | — (обязательна) |
| `OPENAI_MODEL` | `gpt-4.1-mini` |
| `OPENAI_TIMEOUT` | `60` |
| `OPENAI_MAX_RETRIES` | `2` |
| `OPENAI_PROXY` | — (HTTP-прокси до OpenAI, если он недоступен напрямую) |
